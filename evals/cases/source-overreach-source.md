# 原始材料（经作者确认的中性摘要）

来源是一场关于星海图具身智能路线的对谈。

团队从一开始同时做机器人的“大脑”和“本体”。其判断是：本体只有进入真实场景，才能完成动作并持续带回物理世界的数据；这些数据才可能帮助智能能力继续训练和修正。

围绕这条路线，外界提出过两类挑战：一类在问这条因果关系是否真的成立，例如真实场景采集的数据是否能改善目标任务；另一类在问团队是否承受得住当前做法，例如为什么不只做模型、为什么不只做硬件、人才、资金、供应链和数据是否足够。

对谈中，团队调整过数据采集方式、产品顺序、组织优先级、资源投入和创始人的时间分配。材料没有证明一个适用于所有复杂项目的“聚焦”标准，也没有证明每一类投入都应该带回“下一轮信息”。

# 修改、Review 与阅读依赖

在修改既有内容、做内容 Review，或需要检查文章、页面和视觉阅读顺序时读取本文件。执行当前工作区的外部内容底线，但不要把它机械套成固定叙事模板。

## 按读者路径冷读

暂时忘掉创作讨论和作者脑内信息，按读者实际会看到的顺序逐个阅读团块检查：

1. 我此刻知道正在讨论什么对象、任务或条件吗？
2. 当前判断隐含哪些前提、比较基线、状态、因果或说话者立场？它们在哪里出现？
3. 当前材料实际支持多强的结论？
4. 下一句、下一段或下一页为什么此时出现？
5. 如果读者先看到强调文字、左栏、右栏或箭头，关系仍然成立吗？

观点、案例、数据、过程和矛盾都可以成为入口。观点先行时，让紧邻信息构成完整入口；不要让抽象结论独自占据第一视觉焦点，再要求读者向后倒推对象。

## 句、段、篇与页面

- 句子在当前语境中要能辨认谁做什么、作用于什么，以及必要的条件、结果和责任主体；`它`、`这说明`、`这里`等指代必须唯一。
- `所以`、`但是`、`反而`、`意味着`等关系词要对应真实的因果、转折、对照或推导，不能替代中间推理。
- 每段完成一个可识别的认知推进，但不强制背景—证据—结论格式，也不以段数、长度或标题数量判断质量。
- 全文保持主要对象和中心判断的适用范围。案例、数据、工具和技术概念必须服务上位判断；没有认知增量的重复收束、结果页或 CTA 可以删除。
- 跨页可继承前页已经展示且指向唯一的对象和概念；对象、时间、案例、责任主体或抽象层级切换时重新锚定。
- 左右结构必须有稳定比较轴和相同抽象粒度。箭头只表达材料支持的先后、依赖、因果、责任交接或反馈，不能把并列画成因果或把反馈信号画成完整闭环。

## 修改方法

1. 从全部有效材料恢复对象、判断、证据、边界和关系；
2. 找到最早断裂层：术语、句子、段落、整篇、跨页或最终视觉顺序；
3. 写清原本要表达的关系，例如“主体 → 动作 → 对象”“前提 → 推论”“案例 → 判断”；
4. 重写最小能够独立恢复逻辑的完整单元；
5. 如果修改改变后续内容的对象、定义或前提，同步重写下游受影响单元；
6. 对最终可见版本重新冷读。

不要用追加桥句、“补充说明”或局部换词覆盖已经改变的基础判断。

## Review 输出

只报告能够由材料与最终可见内容证明、且会影响理解的问题。每条采用：

`具体位置 → 读者当前理解 → 缺失前提或错误关系 → 可能误读 → 最早回修层`

标题长短、段数、页数、是否有封面、总结、CTA、主视觉或固定版式，本身不是缺陷。只有这些选择导致语义缺失、阅读顺序错误或不可读时才指出。

## 两个真实反例

可通过：

> 看完这场关于具身智能的对谈，我想谈谈“聚焦”。

同一阅读团块交代了当前对象与写作意图。

应回修：

> 看完这场关于具身智能的对谈，我想重新谈谈“聚焦”。

“重新”隐含作者此前已经谈过或形成过相关立场。材料没有这段前史时，删除该依赖，或先展示能够支持它的材料。

应回修：

> 真正的聚焦不是少做，而是每一环都带回新信息。

如果第一阅读团块尚未说明谁正在做什么、为什么这些环节同时出现，这个判断要求读者先接受作者脑内前提。先补足对象、情境与矛盾，或将它们放进同一完整入口。

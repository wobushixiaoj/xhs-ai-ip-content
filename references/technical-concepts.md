# AI 内容中的概念与责任边界

当这些概念承担推理任务时读取本文件。先用一句人话说明它在当前业务任务中解决什么问题，再保持全文定义一致。

- **模型**：理解输入、推理和生成内容。
- **Agent**：接收目标，读取状态，选择动作，观察结果，并决定继续、退回或停止。
- **Tool**：面向 Agent 暴露的可调用能力；可以直接暴露 API，也可以包装服务或编排多个 API。
- **API／服务**：底层执行接口或已有业务能力，不与 Tool 写成线性替代关系。
- **Loop**：节点内部的生成、判断和修复。
- **Graph**：节点、状态、条件路由和失败退回。
- **Eval**：判断规则与证据。
- **Trace**：执行过程记录。
- **人**：材料明确保留给人的判断、授权、审批或责任。

注意：

- Graph 节点不等于 Agent；单次生成不自动称为 Agent；
- 收到反馈信号不等于形成闭环，还要说明谁依据什么规则判断、下一步动作如何触发、结果怎样再次被观察；
- Tool 不自动决定业务合规性或代替服务端规则；
- 写技术结论前先交代业务任务、参与者、已有能力和具体矛盾，避免技术词替代问题定义。

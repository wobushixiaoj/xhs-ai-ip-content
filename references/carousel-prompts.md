# 图文拆页与 imagegen 提示词

仅在用户明确要求连续图文页、逐页可见文案、页面阅读顺序 Review 或 imagegen 提示词时读取本文件。先确认正文的对象、判断、证据和边界已经稳定；拆页不是用视觉补内容缺口。

## 拆页

先写清连续推理，再在自然语义断点拆页。每页应增加对象、证据、关系、判断、边界或行动依据中的至少一项；没有认知增量的封面、过渡页、总结页或 CTA 不默认生成。

后页可以继承前页已经展示、指向唯一且仍在连续讨论中的对象和术语。以下不能继承：创作讨论、作者脑内背景、未展示的来源、指向不唯一的代词，以及对象或层级切换前的旧主语。

页面内容按读者最终的从上到下、从左到右顺序写。观点可以先出现，但第一完整阅读团块必须让读者识别当前对象、任务或条件。左右对照要有同一比较轴与抽象粒度；流程和箭头只表达已经成立的真实关系。

## 每页交付

每页只包含两个必需部分：

1. **页面可见内容**：逐字列出读者会看到的文字，顺序就是最终阅读顺序；
2. **imagegen 提示词**：可单独复制使用，写明画布尺寸、全部可见文字、阅读顺序、必要关系、素材约束和禁止项。

默认尺寸为 1080×1440；用户指定其他尺寸时使用指定尺寸。`第 N 页` 与 `提示词` 可作为协作文件标记，不必出现在图片中。

## 提示词映射

提示词必须：

- 逐字列出所有要出现在页面上的中文、英文、数字和来源文字；
- 描述读者先看到什么、再看到什么，以及必须保留的对象、比较、因果、层级或反馈关系；
- 说明真实截图、用户指定素材、必须完整可见的元素及允许裁切范围；
- 不使用“上一页”“同上”“沿用前页”“保持之前风格”等相对指令；
- 不创造正文没有的案例、事实、关系、因果或作者认识变化；
- 不为了视觉简洁改写、缩短、遗漏或替换已确认的页面可见文字；
- 不默认要求 HTML、PNG、CSS、SVG 或旧模板。

先把页面可见内容原样复制到提示词的“必须逐字显示的文字”区，再补充构图和关系说明。不要把每一句重新套上引号后手打，也不要把全角／半角标点、中文双引号／单引号、数字或英文符号按“看起来差不多”替换。提示词完成前，逐行比较页面可见内容与提示词中的文字区；任一字符不同都回到提示词修正。

风格、颜色、字体、版心和主视觉只有在用户要求或确实帮助理解时才写入提示词；它们不是页面合同。

## 页面与图片 Review

先按最终可见顺序检查语义：第一阅读团块是否建立对象；每个判断的前提是否已出现；相邻团块为什么相连；左右比较和箭头是否表达真实关系。文字语义有问题时回到页面内容；只有语义完整而图片遮挡、裁切或不可读时，才指出实际图片问题。

用户明确要求实际生成或编辑图片时，将已确认的页面提示词交给 `imagegen`。没有该授权时，只交付页面文案与提示词。
